SAMPLE DATA: fictional Acme Widgets, written for the aacc-spar demo.

A half-built checkout flow went live in 2026-01 because its feature flag defaulted ON when the config row was missing.

**Why:** A flag that defaults ON turns 'not configured yet' into 'shipped'.

**How to apply:** Feature flags default OFF. Turning a feature on is an explicit, reviewed change.
